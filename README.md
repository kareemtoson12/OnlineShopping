Online Shopping Application
## 🔗 [Live Demo](https://drive.google.com/file/d/1Fqs4taFnagrBvxfw8ZOpILJkz2s06gDQ/view?usp=sharing)
The Online Shopping Application provides a seamless platform for customers to explore and purchase products while equipping admins with robust tools for inventory management and sales analysis.
![Image](https://github.com/user-attachments/assets/e926ff6e-9509-4de5-8781-f7d76d6d71b7)

## 🌟 Key Features

### 👤 Customer Features

- 🔐 **Sign-Up & Login**  
  Secure user authentication with "Remember Me" and "Forget Password" options.

- 🧭 **Browsing & Navigation**  
  Intuitive UI to browse product categories and detailed product pages.

- 🔍 **Advanced Search**  
  Search products using:  
  - Text input  
  - Voice commands  
  - Barcode scanning via camera

- 🛒 **Shopping Cart Management**  
  - Add, remove, and update product quantities  
  - View total order cost before checkout

- 📍 **Delivery Location**  
  GPS / Google Maps integration for accurate delivery address selection.

- 🎂 **Personalization**  
  Allows users to set birthdates using a calendar for tailored experiences.

---

### 🛠️ Admin Functionalities

- 📦 **Product Management**  
  - Add, edit, or delete products and categories  
  - Manage stock quantities per product

- 📊 **Transaction Reports**  
  - Generate order reports by specific dates

- 💬 **Feedback & Ratings**  
  - Collect and analyze customer reviews and order ratings

- 📈 **Sales Analytics**  
  - Generate sales charts for top-selling products

---

### 🗄️ Database & Backend

- **Firebase** for:  
  - Real-time data storage  
  - Secure and seamless backend operations

---

## 🚀 Technologies Used

- **Flutter**  
- **Firebase (Auth, Firestore, Storage)**  
- **Google Maps API**  
- **Stripe** for secure payment  
- **Barcode Scanner**  
- **Voice Recognition**  
- **State Management:** GetX / BLoC  
- **Architecture:** MVC
